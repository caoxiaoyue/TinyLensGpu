# M4/M5 subhalo 证据比较：先验宽度敏感性研究

对象：`examples/pix_src_demo_operator/pipe/subhalo_0946/model.py`
数据：SLACS J0946+1006，201×201 图像，`DPIX = 0.05` arcsec
日期：2026-09-21

**版本说明：** 下文的数值结果和冻结 spec/JSON 描述属于历史 SIS 实验。
当前管线已切换到 Vegetti 风格的 Pseudo-Jaffe，并移除了冻结配置：
M4/M5 直接读取全局变量，用同一构建函数和 M2/M3 后验计算先验；实际先验保存在
stage pickle 的 `prior_specs` 中，不再生成 `comparison_prior.json`。
旧输出不作为当前模型的缓存继续使用；当前模型需重新运行才能得到新的证据值。

## 1. 设计

原脚本的结构问题：旧 M4 在 M3 后验基础上加 subhalo，直接比较 `lnZ(M4) − lnZ(M3)`
作为 subhalo 证据。但 M3 与 M4 的光滑模型先验来源不同（M3 用 M1 后验，旧 M4 用
M3 后验），所以差值混合了 (a) subhalo 效应、(b) 光滑先验体积变化、(c) Occam
因子。

改为：

| stage | 角色 | smooth mass 先验 | λ 先验 | ρ |
|---|---|---|---|---|
| M2 | 源正则化标定 | — | — | — |
| M3 | 先验构建（**不参与证据比较**） | — | — | — |
| M4 | smooth null 模型 | M3 后验 top-hat + 10% padding，**下限 σ 地板** | M2 中值 ±0.5 dex log-uniform | 固定 M2 中值 |
| M5 | M4 + SIS subhalo | **与 M4 逐参数完全相同（同一份冻结 spec）** | 同 M4 | 同 M4 |

只报告 `ΔlnZ = lnZ(M5) − lnZ(M4)`。共同先验一次生成、写入
`output*/comparison_prior.json`，两臂直接读取同一对象。

当时的关键实现细节：

- `log_lambda_reg` 存的是**自然对数**，±0.5 dex 必须写成 `0.5*ln(10) =
  1.1512925465`。用 `prior_type="uniform"` 作用在 lnλ 上即等价于 λ 上的
  log-uniform。
- `PIPELINE_SCHEMA` 指纹包含先验构造规则（含 σ 地板值），缓存 pkl 的 schema 不
  符即强制重算，避免跨先验静默复用。
- 当时在算 ΔlnZ 前逐参数比对两臂 `(type, settings, limits)`；当前由共用构建函数
  保证一致，回归测试与独立 smoke 验证这一行为，不再保留单独的运行时比对层。

## 2. 比较结果：ΔlnZ 不收敛

四轮运行，只改共享光滑先验的 σ 地板（其它设置完全一致，`n_live = 1000`）。
"边界"列是 `_prior_edge_report` 对 M5 的标记。

| 地板 | M4 lnZ | M5 lnZ | ΔlnZ | M5 θ_E | M5 γ | M5 θ_E_sub | M5 贴边参数 |
|---|---|---|---|---|---|---|---|
| ~2.9σ (quantile+10%) | 5782.07 | 5808.54 | **+26.47** | 1.3978 | 2.0334 | 0.0116 | θ_E 44.7%, γ 35.1% |
| 5σ | 5778.46 | 5817.38 | **+38.92** | 1.3962 | 2.0141 | 0.0147 | θ_E 57.6%, γ 23.2% |
| 10σ | 5772.92 | 5836.65 | **+63.73** | 1.3919 | 1.9490 | 0.0232 | θ_E 76% |
| 20σ | 5767.39 | 5860.72 | **+93.33** | 1.3835 | 1.8570 | 0.0418 | θ_E 76% |

（M3 的 lnZ = 5759.27，仅作参考，不是比较基线。）

两个可检验的算术事实：

1. **M4 侧完全规范**：先验宽度每翻一倍（8 个光滑参数），`lnZ(M4)` 恰好下降
   `8·ln2 = 5.55`。实测 5782.07→5778.46（−3.61，对应 5σ/2.9σ = 1.58 倍）、
   5778.46→5772.92（−5.54）、5772.92→5767.39（−5.53）。这说明 M4 的似然相对于
   先验宽度是 δ 函数型的。
2. **M5 侧反向上升**：先验变宽本应付出同样的体积项，但 M5 的 lnZ 每次都在**上涨**
   （+8.84、+19.27、+24.07）。上涨意味着新增体积里的似然比旧体积的平均值高得多。

结论：**ΔlnZ 由共享先验宽度控制，从 +26 增长到 +93 仍未见平台。** 这个量目前不是
subhalo Bayes factor。

## 3. 诊断过程（每一层的实际数值）

### 3.1 ΔlnL 分解：增益不是简并假象

用真实似然在 M5 后验中位数处分解（`verify_lm_decomposition.py`，v2 输出）：

```
L_M4(M4 median)                    lnL = +4832.28
L_M4(M5 smooth median, 无 subhalo)  lnL = +4750.51   ← 光滑参数移动反而差 81.8
L_M5(M5 median)                    lnL = +4871.48
L_M5(M5 median, theta_E_sub = 0)   lnL = +4750.51   ← 与上一行精确一致（不变性校验）
```

即 subhalo 在固定光滑参数下贡献 `ΔlnL = +120.97`，真实存在。

物理量核实（`probe_subhalo_effect.py`）：TinyLensGpu 的 SIS 偏折是**常数**
`α = θ_E`（`sis.py: scale = theta_E / radius`），不是点质量的 `θ_E²/b`。所以
θ_E = 0.0116 的 subhalo 在像点造成 1.164e-2 arcsec（0.23 像素）的源面位移。像 1
处切向特征值 `λ_t = 0.0154`（μ = 58，紧贴临界曲线），放大率变化 +2.25%；弧像像素
上 `|Δln μ|` 中位数 2.2%、均值 8.9%，极值 4.85。κ = γ = θ_E/(2b) = 0.0035。

### 3.2 质量/位置扫描：光滑、单峰、局域

```
θ_E_sub   0(无)    0.002   0.005   0.008   0.0116  0.015   0.02    0.03    0.05    0.08     0.1
lnL       4750.51  4787.37 4828.28 4855.83 4871.43 4861.76 4806.41 4564.70 3729.39 1556.98  -388.47
```

位置依赖性同样光滑局域：移动 1 像素 −0.68、4 像素 −10.5、20 像素 −74.8，挪到空角落
(4,4) 回到 4749.17（≈ 无 subhalo 值）。没有数值跳变。

### 3.3 θ_E / γ 切片与"山脊追踪"

- 在 **5σ** 后验中位数处切片：M5 的 θ_E 峰在 1.3954（−5.8σ_M3），γ 峰在 2.010
  （−4.4σ_M3）——峰在 5σ 先验**之外**。
- 在 **10σ** 后验中位数处切片：M5 的 θ_E 峰降到 1.3914（−10.5σ_M3），峰 lnL 从
  4883.2 升到 4902.7——峰随其它参数放松而继续下移。
- `probe_ridge_chase.py`（在 10σ 解处做坐标上升：θ_E / γ / θ_E_sub 轮流一维扫描）
  **一个循环即收敛**：θ_E = 1.3919（−9.9σ_M3）、γ = 1.94897、θ_E_sub = 0.0232，
  lnL = 4901.53（比 null 最好的 4832.29 高 **70**，即 Δχ² = 139）。所以 10σ 处
  存在**有限的内部最优解**。

**但在 20σ 解处重复同一追踪，也立刻收敛，而最优值更好**：

| 种子解 | θ_E | 偏移 | γ | θ_E_sub | 收敛点 lnL_max |
|---|---|---|---|---|---|
| 5σ 后验中位数附近 | 1.3954 | −5.8σ_M3 | 2.0100 | 0.0147 | ~4883 |
| 10σ 后验中位数 | 1.3919 | −9.9σ_M3 | 1.9490 | 0.0232 | 4901.53 |
| 20σ 后验中位数 | 1.3835 | −19.7σ_M3 | 1.8570 | 0.0418 | 4926.11 |

即：不是一条平坦山脊，而是**一串彼此分离、且一个比一个好的局部最优解**（ladder）。
坐标上升在每一级都正常收敛，但级与级之间的 lnL 持续上升（4883 → 4902 → 4926），
subhalo 质量同步增大（0.0147 → 0.0232 → 0.0418），主透镜变轻变圆、外剪切变小。
放宽先验就等于允许积分爬升到更高的一级，所以 ΔlnZ 随先验宽度单调增长。

### 3.4 管线新增的两个常驻诊断（本轮发现后加入）

1. `_prior_edge_report` 的判据已修：原规则"后验落在先验外侧 2% 内即报警"在先验远宽于
   后验时失效（10σ 轮里先验外侧 2% 的窗口 1.7e-4 比后验自身 σ = 2.15e-4 还窄，健康后
   验也报 79%）。现改为**基于后验自身尺度**：后验中位数距先验边界不足
   `PRIOR_EDGE_SIGMA = 3` 个后验 σ 才报警（退化后验回退到权重规则）；外侧 2% 权重仍
   打印但仅作参考。
2. `_solution_drift_report`（`SOLUTION_DRIFT_WARN_SIGMA = 5`）：逐参数报告该臂光滑解
   相对 M3 解的偏移（单位 σ_M3）并标记超过 5σ 的参数。**这是识别"先验在替代数据做工"
   的直接信号**——本轮 M5 的 θ_E 漂移到 −20σ_M3，与边界标记同时出现，说明所报 ΔlnZ
   依赖先验宽度。

自检：`smoke_m4_m5.py` 59 项断言全绿（含两个新诊断的正/反用例与 10σ 漂移用例）。

## 4. 物理图像与结论

滑动方向是：(θ_E ↓, γ ↓, e1 ↓, γ1/γ2 ↓, subhalo 质量 ↑)。也就是说 subhalo 的
小尺度微扰与主透镜的归一化、径向斜率、椭率、外剪切之间互相交换——这就是经典的
**substructure 与光滑模型简并**。区别在于：在这个数据上它**没有终点**，每次放宽先
验都出现一个拟合更好的解（Δχ² 从 139 继续增大）。

因此：

1. **不能把当前 ΔlnZ 当作 subhalo 探测显著性**。它是先验宽度依赖的。
2. 用户最初的方案（M3 后验分位数 ±20% 或 ±10% padding 的 top-hat）在"两臂先验体积
   相同"这一点上是对的，但**宽度本身不够**：扰动臂的最优光滑解可以落在距 M3 中位数
   10σ 甚至 20σ 外的地方，任何围绕 M3 的 top-hat 都会系统性地偏置 ΔlnZ。

## 5. 建议（按推荐度排序）

1. **用物理先验替代 top-hat**：主透镜参数（θ_E、γ、椭率、剪切）应由独立信息给出
   ——恒星运动学、光度模型的轴比与位置角、SLACS 群体标度关系。这样简并滑动被*物理*
   排除，而不是被任意宽度排除。这也是 Vegetti 组做法中"固定/约束部分主透镜参数"的
   实质。
2. **mock 标定**（用户原计划）：用完全相同的 M2→M5 流程跑无 subhalo 的 smooth-only
   mocks，得到 ΔlnZ 的假正分布。因为 mock 里同样存在这条简并滑动，假正分布会自动
   吸收这个效应；把实测值（以及 Δχ²、恢复的 subhalo 质量与位置）与分布比较，才是可
   发表的探测陈述。
3. **条件证据**：把光滑参数固定在某个解（如 M4/M3 中位数）上，只让 subhalo 参数自
   由，报告条件 Bayes factor。代价是结论依赖于所固定的光滑模型，但它是保守、可复现
   的。
4. **ρ 敏感性**：当前 ρ 固定为 M2 中值，结果是条件证据。建议 ρ ∈ {q16, q50, q84}(M2)
   各成对重跑。

## 6. 局部位置先验的控制实验（已完成）

### 6.1 问题

全图均匀位置先验下 M5 的光滑解漂移 8–20σ（§4）。用户指出这与 Nightingale 22 等工作的经验一致：
把位置完全放开时 subhalo 会跑偏；他们的做法是把透镜平面切成小格、每格内单独搜索 subhalo，最后汇总。
所以先做**局部控制实验**：把位置先验限制在左上弧残差附近。

### 6.2 设计

- 参考位置：`(center_x_subhalo, center_y_subhalo) = (−0.70744, +1.00661)` arcsec，取自
  `output/stage_m4.pkl` 的 medians（即绘图里黑色五角星的位置，r = 1.23″）。
- 先验：截断高斯，σ = 0.2″，每轴 ±3σ → x∈[−1.307, −0.107]，y∈[+0.407, +1.607]。
- 有效搜索面积按 `2πσ² = 0.251 arcsec²` 计入 look-elsewhere（全图 101.0 arcsec²，即 1/402）。
- 其余不变：共享光滑先验（5σ 地板）、λ 取自 M2、ρ 固定、两臂 nuisance 逐字一致。
- 开关：`SUBHALO_POSITION_MODE` / `SUBHALO_POSITION_CENTER` / `SUBHALO_POSITION_SIGMA`，
  或命令行 `--subhalo-position CX CY --subhalo-position-sigma S`；`full_image`、`model_square` 保留。

### 6.3 结果（`output_m4m5_local/`）

| `logZ(M5)` | +5804.514 |
| `ΔlnZ` | **+26.047** |

**判据 1 通过**：subhalo 落在五角星（左上弧残差）上，而全图先验的三次运行都落到别处。
**判据 2 部分通过**：漂移从 8–20σ 降到 3–5σ（θ_E −4.85σ、center_x_mass +4.68σ、gamma1 +3.10σ、

source template 或旧解本身被先验拉长所致，值得用残差位置上的 θ_E_sub 似然切片单独确认。

### 6.4 与全图结果的对照（关键）

```text
                位置                  r         θ_E_sub      r<1.43 的后验权重
局部(5σ)        (−0.829, +1.029)     1.32″     0.0122       1.000
全图(2.9σ)      后验弥散             2.13″     0.0152       0.000
```

**全图先验的后验对内环（r < 1.43″）给出的权重是 0**：位置一旦放开，
"已知 subhalo 位置"这个模式在证据积分的后验里完全消失，全部概率质量跑到 2.1–4.5″
（部分超出 2.5″ 的建模掩模）。这不是"多峰但主峰在内环"，而是内环模式被彻底压制。

修正一个我中途的错误判断：J0946+1006 是**双爱因斯坦环**系统（SLACS VI / Gavazzi et al. 2008：
内环 R_E1 = 1.43″±0.01″ @ z_s1 = 0.609，外环 R_E2 ≈ 2.0″ @ z_s2 = 0.709，内环探测见
Vegetti et al. 2010）。所以 1.9–2.2″ 那片**确实有真实的（较暗的）外环**，
不能简单说成"跑到没有发射的建模区边缘"；但 4.0–4.5″ 已超出掩模，那部分才是真正无约束的外围。
数据核对：内环区（1.2–1.8″）均值 SNR 10.9–18、峰值 30–35；2.0–2.4″ 环带均值 3.7、峰值 9.6，
而掩模外（2.5–3.0″）均值 3.8、峰值 7.7——2.0–2.4″ 与掩模外几乎无对比，说明该噪声图偏乐观，
任何此处的 subhalo 声明都需要假正标定。

### 6.5 逐格搜索的合并规则（为下一步预留）

多格结果**不能取 max ΔlnZ**。若各格先验互不重叠且覆盖整个搜索区，正确合成是面积加权

    Z_total = Σ_i (A_i / A_total) Z_i

（等价于把各格局部先验拼成一个分段先验）。用高斯格时相邻格的 2πσ² 有效面积会重叠、造成重复计数，
所以逐格搜索应优先用**平铺的均匀小格**（方格或正六边形，边长 L 使 2πσ² ≲ L²），而不是相邻高斯格。
这条规则仍适用于逐格搜索；当前管线没有单独的冻结配置打印层。

### 6.6 先验体积标定与收敛性检验结果（关键）

局部配置下，8 个质量参数的半宽从 5σ 到 10σ **全部精确翻倍**（`comparison_prior.json` 实测：

```text
center_x_mass 0.005793 → 0.011587 (x2.0000)   center_y_mass 0.009239 → 0.018477
e1_mass       0.020462 → 0.040924             e2_mass       0.016366 → 0.032731
gamma         0.067851 → 0.135702             gamma1        0.010720 → 0.021440
gamma2        0.007808 → 0.015617             theta_E       0.004297 → 0.008593
```

故 `ln(V10/V5) = 8·ln2 = 5.5452`，与 M4 实测下降 5778.467 − 5772.930 = 5.5370 一致。
由于 10σ 盒严格包含 5σ 盒且似然相同，`lnZ_M5(10σ) ≥ 5804.514 − 5.545 = 5798.97` 是下界。

**实测结果（局部位置先验，三轮全部完成）**：

| 地板 | `logZ(M4)` | `logZ(M5)` | `ΔlnZ` | `θ_E_sub` | M5 的 θ_E 漂移 | θ_E 边界权重 |
|---|---|---|---|---|---|---|
| 5σ | 5778.467 | 5804.514 | **+26.05** | 0.0122 | −4.85σ_M3 | 46.9% |
| 10σ | 5772.930 | 5821.093 | **+48.16** | 0.0196 | −9.85σ_M3 | 72.7% |
| 20σ | 5767.384 | 5849.326 | **+81.94** | 0.0330 | −19.80σ_M3 | 88.3% |

（M4 每轮精确下降 8·ln2 = 5.545 = 体积效应；M5 反而多赚 +22.1、+33.8，**加速上升**。）

**结论：局部位置先验没有让 ΔlnZ 收敛，也没有让质量后验稳定。**

三个判据都指向同一机制：

1. `ΔlnZ` 单调上升且加速（26 → 48 → 82），每翻倍先验体积变化 e²²–e³⁴。
2. **M5 偏好的 θ_E 永远落在先验下边缘之外**：每轮都停在距边缘 0.84–0.85 个后验 σ 处，
   漂移量恰好等于地板值（−4.85、−9.85、−19.80 σ_M3），边界权重 46.9% → 88.3%。
   即"无论给多宽，M5 都想要更低"——与 §7 的阶梯完全一致。
3. `θ_E_sub` 随先验宽度膨胀 0.0122 → 0.0196 → 0.0330（×2.7）：
   位置被钉住后，subhalo 无法再往外跑，于是改用**增大质量**来继续补偿。

唯一稳健的量是**位置**：三轮都是 (−0.83,+1.03)、(−0.77,+1.04)、(−0.74,+1.04)，
即落在已知残差上；**质量不稳健，证据更不稳健**。

因此本次控制实验的可靠产物只有"位置"这一项。局部配置的 ΔlnZ 与 θ_E_sub
**同样不能作为探测显著性/质量测量引用**。这正面回答了两个问题：
局部先验解决了"找不到已知位置"（全图先验对内环权重为 0），但没有解决
"证据由先验宽度主导"，因为根因（§7 未截断 SIS 的远场简并）与位置自由度无关。

对照：全图 M5 的下界是 5817.380 − 5.545 = 5811.84，实测 5836.652，多赚 24.8 → 同一机制。

## 7. 根因：未截断 SIS 的远场与 (θ_E, shear) 简并

§4 的"阶梯"和 §6.4 的"内环模式权重为 0"有一个共同的、可量化的原因，与先验宽度无关。

`TinyLensGpu/PhysicalModel/LensImage/Parametric/Mass/sis.py:24` 是 `scale = theta_E / radius`，
即 **SIS 的偏折模长恒为 θ_E，不随距离衰减**（这是 SIS 的固有性质：α(θ) = θ_E 对所有 θ 成立）。
因此放在弧外侧远处的 subhalo 仍然偏折弧的光线，其偏折场在弧区的结构是
"向外的径向单位向量 × θ_E_sub"——在 |p| 远大于弧半径时，它趋于**常数向量 + 线性梯度**。
而这两项恰好等价于主透镜的 **θ_E**（常数偏折）与**外剪切**（线性梯度）。

`probe_sis_farfield.py` 把该偏折场投影到 span{1, x, y}（每个分量 3 个基函数，共 6 参数）
并给出"可由常数+梯度表达"的功率占比：

```text
  |p| (arcsec)   可由 (常数+梯度) 表达     不可表达（真正的局域曲率）
      1.32"            84.6%                    15.4%     ← 控制实验的位置（内环）
      2.00"            96.2%                     3.8%
      2.50"            98.4%                     1.6%
      4.00"            99.8%                     0.2%
      4.50"            99.85%                    0.15%
```

结论链：远处的 SIS subhalo ≈ 一个自由的 (Δθ_E, Δγ1, Δγ2) 扰动 → 数据偏好一个与 M3 解
略有差异的 (θ_E, shear) 组合 → 模型通过"加一个远处的 SIS 并协同移动 θ_E/γ"来买似然 →
未截断剖面使"越远"没有任何代价 → **阶梯没有终点，ΔlnZ 随先验体积单调增长**；
同时内环（真正的局域信号所在）被这个几乎免费的简并方向彻底压过（后验权重 0）。

**修复方向**：subhalo 应使用**截断剖面**（pseudo-Jaffe / tNFW，即文献做法），使偏折在
截断半径外衰减，从而给"远处位置"物理惩罚；局部位置先验可作为诊断/控制实验保留
（它是让内环模式可见的手段，而不是根因修复）。
